🎵 Harmony Music School
Welcome to Harmony Music School, a web project designed to help users explore and enroll in music courses. This website provides information about the school, available courses, and contact details.
📌 Features
•	Homepage: Welcomes users and introduces the school.
•	Navigation Bar: Links to Home, About Us, Courses, and Contact pages.
•	Course Listings: Displays available music courses.
•	Dark Mode Toggle: Allows users to switch between light and dark themes.
🛠️ Technologies Used
•	HTML, CSS, JavaScript for frontend development.
•	Responsive Design to ensure mobile and desktop compatibility.
